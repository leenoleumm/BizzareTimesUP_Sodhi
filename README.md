# Учебная практика УП.01.01
Тема: Проектирование и разработка базы данных для новостного агентства «Bizzare Times».
Студент: Соди Г. М., группа 4ИСИП-123.

## Функционал приложения:
- Авторизация и регистрация с хешированием паролей
- Капча после 3 неверных попыток входа
- Разграничение ролей (Администратор, Читатель, Писатель)
- Просмотр, поиск и фильтрация статей
- Панель администратора (CRUD для статей, пользователей и категорий)
- Смена пароля
- Смена темы (светлая/тёмная)
